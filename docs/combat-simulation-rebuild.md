### 최신 수정 — 진입 후 시전 이력과 청룡진 대기

이 절은 아래의 ‘전부 쿨이면 횟수 부족이어도 전환’, 난무 최소1회 규칙을 대체한다. 이력이 없는 단순 쿨 상태로 조기 전환하지 않는다.

- 스탠스 진입마다 해당 진입의 시전 횟수와 지정 카드별 시전 여부를 기록한다. 이전 스탠스 방문에서 발생한 쿨과 현재 방문에서 실제 시전하여 발생한 쿨을 구분한다.
- 전환 직후 지정 스킬들이 쿨이어도 아직 이번 진입에서 사용하지 않았다면 원본 순서를 유지하며 쿨을 기다린다.
- 전환 사용 기준은 **첫 난무만1회, 이후 서로 다른 난무 스킬2개, 집중3회**. 첫 난무 예외는 전투 시작에만 적용하며 목록 반복·360기믹 종료에서 재발급하지 않는다. 시전 시작으로 인정하고 취소·넘어짐·미적중이어도 시전 이력/쿨을 유지한다. 집중 적룡필살도 포함한다.
- 이번 진입에서 사용하여 쿨인 상태와 전환 사용 기준을 만족하면 전환을 판단한다. 단순히 기준 횟수에 도달한 즉시 나머지 지정 카드를 삭제하는 것으로 해석하지 않는다. 남은 미사용 카드가 있는 경우의 우선순위는 아래 확인 항목으로 남긴다.
- 적룡필살 예약 대기는 기존 계약을 유지한다. 시전 취소된 필살은 사용/연가심공 소모로 처리하며 예약을 무한 재시도하지 않는다.
- 청룡진은 난무에서 자체 쿨이 준비되어도 즉시 사용하지 않는다. **맹룡열파 잔여 쿨이 1초 이하**가 된 뒤 기존 입력·행동 제약을 만족하면 시전한다. 맹룡열파가 이미 준비된 경우도 조건을 만족한다. 쿨이 준비되기 전에 청룡진을 강제 사용하지 않는다.
- 청룡진의6초 버프는 실제 시전 시작부터 흐른다. 대기 중에는 버프를 시작하지 않는다. 정책의 대기 해제 조건과 실제 시전 시각은 입력 지연 때문에 다를 수 있으며 로그에 둘 다 기록한다.
- 최초 난무에서 맹룡열파를 사용하지 않는 원본 구성, 맹룡열파 미지정 구성에 같은 대기 규칙을 적용할지는 사용자 확인 전 임의 스킬 추가/정렬로 해결하지 않는다.

추가 확정: 집중에서 유성강천·적룡포·굉열파를 시전하여3회를 채웠고 다음 사두룡격이 이번 진입에서 미사용이지만 아직 쿨이라면, 사두룡격을 기다리지 않고 이번 집중 구간에서 생략한 뒤 난무로 전환한다. 사두룡격을 사용·취소 처리하지 않고 ‘전환 기준 충족 후 쿨 대기 생략’으로 기록하며 쿨/미사용 시간은 그대로 유지한다. 사두가 준비된 경우까지 무조건 생략하는 규칙으로 확대하지 않는다. 적룡필살 예약이 있으면 기존 예약 대기 우선 규칙을 유지한다.

### 최신 확정 보완 — 필살 임계값·피격·360 준비

이 절은 아래의 오래된 정책 후보와 미확정 표기보다 우선한다.

- **F2 확정:** 적룡필살은 항상 연가심공과 함께 사용한다. 세 가지 정책 선택 제안은 폐기하고 사용자 지정 대기 기준 N초(1~10초, 7.5 입력 지원)를 사용한다. 집중 진입 시점의 잔여 쿨 C를 평가한다. 사용자가 든 동일값 예시에 따라 **C<=N은 예약**, C>N이면 이번 집중에서 필살을 보류하고 적룡포에 연가심공을 사용한다. C=0도 연가심공과 필살 사용 대상이다.
- 예약 시 연가심공 키는 아직 누르지 않고 일반 집중 스킬을 이어간다. 필살 쿨이 완료되면 진행 모션 종료·행동 제한·백 확보·입력 지연을 거쳐 연가심공 활성화→필살. 다른 스킬 사이에 준비되면 삽입하고 원본 일반 순서로 복귀한다. 일반 스킬 완료 후에도 쿨이 남으면 집중에서 기다린다.
- C>N으로 보류한 경우 같은 집중 안에서 나중에 쿨이 완료돼도 예약으로 뒤집지 않는다. 다음 집중 진입 때 새로 판단한다. 연가심공 없는 필살 시전 경로는 금지한다. 실력 수준은 N을 자동 변경하지 않는다. 초기 UI 기본 N은 별도 선택이며 7.5를 구현 제안으로 둔다.
- **F3/Q7 확정:** 이동 중 피격은 이미 이동한 위치를 유지하고 회복 후 현재 상황에 맞게 경로를 다시 잡는다. 스탠스 전환 중 넘어져도 전환은 완료된다. 전환 종료와 넘어짐 해제는 독립 사건이며 전환 완료가 피격 상태를 해제하지 않는다.
- **F4 확정:** 360줄 기믹 중 난무로 전환하여 종료 시 난무로 준비한다. 준비 전환은 기믹 시간 안에서 실제0.3초 행동으로 기록하며 보스 종료를 미루지 않는다. 실제 전환이 발생하면 기존 연가심공 소멸/새 기회 규칙을 적용하고, 이미 난무이면 가짜 재전환으로 기회를 생성하지 않는다. 쿨/미사용 대기를 초기화하지 않는다. 최초 전투 난무의 연가심공 미사용 정책을 기믹마다 재적용하지 않는다.
- **F1 확정 범위:** 집중3회 이후 쿨인 사두 및 잔여비율50%이상인 굉열파는 이번 구간 생략. 다음 집중에서는 원본에 예정된 해당 구간을 처리하며 생략 스킬을 별도 추가 예약하지 않는다. 다른 스킬로 일반화하지 않는다.

## 스탠스 설계 선행 결정 — 최신 사용자 답변

적용 범위는 절정 중 222 제외. 절제 및 222에 아래 규칙을 자동 적용하지 않는다. Q1/Q2/Q7은 확정됐으며 Q3/Q5는 필요 단계에서 확인한다. 기존 23장 목록 반복만으로 포지셔닝 경계를 확정하지 않는다.

- 난무에서는 난무 스킬, 집중에서는 집중 스킬만 시전한다. 첫 난무만 최소1회, 이후 난무 서로 다른 스킬 최소2개, 집중 최소3회 **시전**으로 전환 조건을 충족한다. 적룡필살도 포함한다. 시전 시작 시 횟수를 증가시키며 이후 취소·미적중으로 되돌리지 않는다.
- 스탠스 변경은 0.3초. 변경 중에도 쿨·버프 시간은 흐르고 이동이 가능하다. 전환과 이동의 겹친 시간을 중복 합산하지 않는다. 변경 전후는 별도 포지셔닝 판단 지점이다.
- 청룡진은 시전 시작부터 **6초**, 치적 +20%. 다른 스킬은 **실제 타격 시점**으로 적용 여부를 판정한다. 정확히 시작+6초에 타격하면 적용하고 그 이후는 미적용한다. 이전 5초 설명과 만료 시각 제외 해석을 폐기한다.
- 연가심공은 스탠스 변경으로 얻는 1회 기회와 키를 누른 뒤의 활성 대기를 구분한다. 키 동작 시간은 0초. 활성화 후 다음 시전 스킬에 자동 적용하고 소모한다. 시전이 취소되어도 환불하지 않는다. 원하는 스킬보다 다른 스킬을 먼저 시전하면 그 스킬에 적용된다.
- 연가심공을 사용하지 않고 스탠스를 변경하면 이전 기회는 사라진다. 전환한 스탠스에서 새 1회 기회를 얻는다. 전투는 난무에서 시작하며 **최초 난무 구간에서는 연가심공을 사용하지 않는다**. 첫 스탠스 전환 이후부터 사용 정책을 적용한다. 이는 게임의 초기 자원 보유 여부에 대한 단정이 아닌 사용자 지정 시뮬레이션 정책이다. 이후 난무에서는 맹룡열파 직전에 활성화하며 맹룡열파를 쓰지 않고 전환하면 활성화하지 않는다. 전환 완료 시 새 기회를 부여하는 것을 구현상 경계로 사용한다. 전환 중 스킬 시전은 불가하며 피격으로 전환 완료를 취소하지 않는다.
- 집중 진입 때 적룡필살 잔여 쿨이 사용자 지정 N초 이하이면 연가심공을 활성화하지 않은 채 보존하고 일반 집중 스킬을 사용한다. 나머지 4개를 모두 사용해도 필살 쿨이 남았다면 집중을 유지하며 기다렸다가 연가심공 활성화 → 적룡필살 시전 후 진행한다.
- 필살이 일반 스킬 진행 도중 준비되면 진행 모션을 끊지 않고 다음 행동 기회에 삽입한다. 준비됐어도 패턴상 사용 불가하면 기존 적룡필살 사용 제약을 지킨다.
- 적룡포에 기회를 소비한 뒤 적룡필살을 다음 집중 진입까지 미루는 동작도 사용자 선택 정책으로 정의한다. 고수/하수라는 설명은 예시이며 플레이 수준이 선택한 정책을 자동 교체하지 않는다.

- 지원 모션(공속 130% 기준): 청룡진 .55, 맹룡열파 .90, 반월섬 .70, 사두룡격 .65, 적룡포 .85, 유성강천 1.25, 굉열파 1.10, 적룡필살 1.30초. 적룡포·굉열파는 2026-09-28 사용자 지정값으로 수정했으며 나머지는 기존 영상 추정 중간값이다. 공속 보정과 입력 지연은 별도로 적용한다.
- 모션 = 기준 모션 × 130 / 현재 실제 공속(%). 실측 공식이 아닌 초기 모델. 입력 지연은 공속 보정하지 않는다.
- P=clamp(수준,60,100). 연계 지연=.2+(100-P)×.00125초, 패턴 변경 지연=.3+(100-P)×.005초. 둘 중 하나만 적용.
- 시전 시작에 쿨 시작, 모션 끝에 합산 피해 1회. 타격 전 취소는 피해 0·쿨 유지·다음 카드 진행.
- 경직 면역: 맹룡열파·반월섬·적룡포·유성강천·굉열파·적룡필살, 시전 중에만 적용. 넘어짐 면역 없음.
- 동시각 처리: 보스 상태 변경 → 타격 → 상태이상 → 행동 완료·판단. 딜 불가 시작 포함. 종료 시각과 같은 타격 포함, 이후 제외.
- 실수 확률(%): ROUND(k×((100-P)/10)^1.2), 버벅임 k=5, 경직7, 넘어짐3. 프리딜 제외. 위험시간 7초에는 경직 기회 2회. 이동 패턴과 다음 패턴의 버벅임 기회. 패턴당 넘어짐 및 딜 불가 포함 시 추가 기회.
- 경직 .5초, 버벅임1초, 기상기 사용 넘어짐2초, 없으면4~6초. 기상기 실제 사용부터26초. 넘어짐>경직>버벅임, 경직 중 넘어짐 가능. 중첩을 단순 합산하지 않는다.
- 뒤잡기 기본 삼각분포 .5/2/2.99초. 시전 중 방향 변경 시 적룡필살도 비백 가능. 백 불가면 적룡필살만 보류한다.
- 3잡은 사용 기회별20%로 한 번만1초 지연. 재평가 시 재추첨하지 않는다.
- 쿨비=1−준비됐지만 미사용한 시간/전체 전투시간. 초기·기믹 중·종료 대기 포함, 종료 당시 활성 쿨 제외.
- 스탠스 대상 모델에서는 실제 청룡진 시간과 연가심공 소모에 맞는 엔진 시나리오를 선택한다. 기존 정적 카드 버프 체크를 중복 적용하지 않는다. 아래 단계에서 언급하는 카드 조건 보존은 원본 설정 보존을 뜻하며 시뮬레이션 실제 버프 판정을 덮어쓰지 않는다.

## 현재 코드 재검토 결과와 검증 부채

`combat-simulation.ts`: 이동 경계 절단, 단일 busyUntil, 일반 쿨 대기 중 적룡필살 준비 누락, 구간별 입력 지연 재설정, 미사용 스킬 쿨비 오류가 남아 있다. 패턴 사이 playerAtBack=true는 Q2 결정에 따라 대체한다. 사용하지 않는 레거시 함수와 임의 보정 함수가 남아 있다.

`boss-timeline.ts`: 방향 변경 ID가 실제 방향인지 변경 이력인지 구분 필요. 1번 마지막 구간이 이전 버전으로 돌아가는 처리, 11번 이동을 회전으로 대체한 처리, 15번 시작 회전 누락을 검토한다. freeDamage를 공격 가능과 동일하게 해석하면 위험이 과소평가된다. 경직 기회 생성은 현재 4초 이하 구간을 누락할 수 있다. 이동 다음 패턴 버벅임도 점검한다.

테스트의 `statusLossSeconds >= 0`, `immune.successfulUses >= vulnerable.successfulUses`는 실제 경직 발생을 증명하지 않는다. 고정 사건 주입으로 원래 강한 주장을 복구한다. 현재 78개 통과만으로 엔진 정확성을 주장하지 않는다.

### R3 뒤잡기 선택 계약

- 연속 공격 우선: 일반 스킬 연속 시전 중 방향이 바뀌어도 계속 공격하고, 스탠스 전환·쿨 대기·패턴 대응 후에 뒤잡기 판단.
- 백 위치 우선: 현재 스킬 모션은 끝낸 뒤 필요하면 이동하고 다음 일반 스킬을 사용. 이동 중에는 스킬을 시전하지 않는다.
- 두 방식 모두 적룡필살의 별도 뒤잡기 규칙은 유지한다. 선택 정책과 플레이 수준은 별도 입력이다.
- 패턴 사이는 이동 비용이 없는 순간 백 확보가 아니다. 필요한 이동을 수행하고 남은 시간에 공격한다. 전환0.3초·쿨 대기와 겹친 이동시간은 중복 합산하지 않는다.
- 실제 이동 완료 전에 playerAtBack=true로 설정하지 않는다. UI 기본값은 기존 연속 공격 동작 보존을 구현 제안으로 두고, 사용자 선택값을 스냅샷에 포함한다.

### R2 전환 예외와 예약 우선순위

- 이번 진입의 시전 횟수와 다음 지정 카드 준비 상태로 판단한다. 진입 전부터 남은 쿨만으로 전환하지 않는다. 집중3회 이후 다음 사두가 쿨인 사례는 생략 후 전환한다. 전환 후에도 쿨과 미사용 시간은 보존한다.
- 필살 보존·대기 예약은 앞서 확정한 일반4개 완료 후 기다림 규칙을 우선한다. 이것은 쿨 중 전환 예외가 필살 예약을 무효화하지 않도록 하는 기존 계약의 적용이다.
- 사두 및 조건부 굉열파 생략은 해당 방문의 로그에만 기록하고 원본 카드를 삭제하거나 성공 사용으로 집계하지 않는다. 다른 스킬에 대한 확대 적용은 금지한다.
- 새 스탠스 진입 후 미사용 지정 스킬은 쿨을 기다린다. 양쪽 스탠스가 모두 쿨이라는 이유로 무한 전환·연가심공 재생성을 하지 않는지 검사한다.

Q3의 행동 프로필 초기값, Q4 전조정보, Q6 실측 쿨비 정의는 여전히 미정이다. Q7 이동 중 피격은 위치 유지 후 경로 재판단으로 확정됐다. Q5는 목록 반복과 스탠스 구간을 별도 개념으로 정의해 단일 청룡진 경계로 가정하지 않는다. 정책 선택 빈도를 실력별 보정 변수로 추가하지 않는다. 60% 행동 초기값은 수치 보정 단계 전에 확인한다.

### P0 원본 입력 계약 및 순수 어댑터 (S0와 함께)

- `page.tsx executeCombatSimulation`에서 현재 편집 세팅과 원본 `cycle`을 실행 순간 불변 스냅샷으로 전달한다. 원본 카드 ID, 스킬 ID, 위치, 정적 버프 체크를 보존한다.
- 원본 카드의 정적 버프 체크는 일반 DPS 계산에 남긴다. 동적 시뮬레이션의 피해 선택은 실제 청룡진/연가심공 상태를 사용한다. 이전 저장 프리셋을 덮어쓰지 않는다.
- 같은 스킬 ID는 공유 쿨을 사용한다. 반복 카드의 개별 설정을 하나의 스킬 객체로 조용히 합치지 않는다.
- 출력 입력에는 실제 공속, 최종 쿨, 기준 모션, 스탠스, 백공격 여부, 백/비백×청룡진×연가심공의 비치명/치명/치확 시나리오를 포함한다.
- 지원 범위는 절정 비222. 절제·222에는 새 규칙 적용을 막고 지원 범위를 안내한다. 데이터가 없는 스킬도 명시적으로 차단한다.
- 스냅샷 ID와 모델 버전을 결과에 연결한다. 실행 후 편집 변경은 결과에 섞지 않고 오래된 결과임을 표시한다.

통과: 원본 순서·반복·카드 ID 유지, 공속/쿨/대미지 어댑터 교차검증, 정적 카드 체크를 바꿔도 동적 버프 판정에 이중 적용되지 않음.

### P1 사이클 컴파일과 사전 검증

- `cycle-compiler.ts`에서 연속된 난무/집중 스킬을 스탠스 구간으로 묶는다. 목록 반복 경계에서도 현재 스탠스와 사용 횟수를 유지하며 원본 카드의 임의 정렬은 하지 않는다.
- 난무 시작, 첫 난무 연가심공 미사용. 반대 스탠스의 카드에 도달하면 최소 시전횟수를 확인하고 전환을 요청한다.
- 일반 카드의 쿨이 남아 있으면 동일 카드를 유지한다. 단 이번 집중3회 이후 사두쿨 또는 굉열파잔여비율50%이상은 사용자 확정 예외로 해당 카드만 생략한다. 남은 준비된 지정 카드를 사용한 뒤 전환을 판단한다. 예약필살 대기는 우선한다. 시전 취소는 사용 처리하고, 일반 대기는 카드를 진행시키지 않는다.
- 적룡필살이 목록에 없으면 자동 추가하지 않는다. 목록에 있으면 사용 가능 선언/추적용으로 보존하되, 일반 순서 실행에서는 제외하고 집중 진입 N초 예약 정책으로만 사용한다. 원래 필살 카드 위치에서 대기하거나 다시 시전하지 않는다. 필살 후에는 미사용 일반 카드 커서로 복귀한다. 반복 필살 카드가 추가 사용 횟수를 만들면 안 된다. 카드별 조건이 실제 동적 피해 입력에 영향을 주는 경우에는 충돌을 명시적으로 검증하고 임의로 첫 카드만 선택하지 않는다.
- 최소 횟수 검증은 동적 필살이 항상 사용된다고 가정하지 않는다. 첫 난무1개 구성은 허용하고 이후 방문은 서로 다른 난무 스킬2개 기준을 검사한다. 이후 방문에서 기준을 충족할 수 없는 구성은 임의 스킬 추가로 해결하지 않고 해당 구간을 안내한다.
- 실제 실행 로그는 원본 카드 ID 및 삽입/대기/전환 원인을 연결한다.

통과: 같은 스탠스만 시전, 첫난무1/이후난무서로다른2개/집중3 인정, 취소도 인정, 반복 목록에서 첫난무 예외 재발급금지, 필살 유무 및 중복 카드 처리 고정 사례.

### P2 기본 엔진 완성 (S1→S2→S3)

보스 타임라인 오류 및 강한 테스트를 복구한 뒤, 스탠스 전환도 이벤트에 포함한다. 전환 0.3초와 이동이 동시 진행될 수 있도록 행동 잠금을 구분한다. 쿨·청룡진 시간은 계속 흐른다. 시전 가능한 조건은 스탠스·쿨·이동/피격·입력 상태로 판단한다.

청룡진은 시전 시작 때 만료시각=start+6초로 기록하고 타격시각<=만료시각이면 적용한다. 버프 만료 이벤트가 같은 시각의 타격보다 먼저 적용되어 버프를 지우지 않도록 한다. 시전 취소 시 이미 적용한 자버프를 어떻게 할지는 현 계약(시전 시작 적용)을 따르며 별도 제거를 추가하지 않는다.

연가심공은 available와 armed를 구분한다. 대상 스킬 직전 0초 키 이벤트로 armed, 다음 시전에서 소모·해당 시전 기록에 적용값 저장. 다른 스킬을 먼저 시전하면 그 스킬에 소비한다. 취소 환불 없음. 스탠스 전환 중에는 스킬 시전을 허용하지 않는다. 자원 갱신은 구현 경계로 전환 완료에 두되 위치·이동·피격 정책과 충돌 여부를 검토한다.

통과: 정확히6초 버프, 직후 미적용, 첫난무 미사용, 전환 후1회, 잘못 먼저 사용한 스킬에 소모, 취소소모, 전환중 이동/쿨 중첩, 기상기·동시각 타격 테스트.

### P3 적룡필살·연가심공 정책

R1에 따라 정책은 사용자 선택이다. 필살 예약은 집중 전환 완료 시각의 잔여 쿨로 해당 방문에 한 번 판단하며, 준비되면 현재 모션 종료 후 사용 가능 상태를 평가한다. 전환 시작 시각의 쿨로 판단하거나 매 반복에서 N을 재평가하지 않는다. N과 뒤잡기 정책을 실행 입력 스냅샷에 보존한다.

- 잔여쿨0: 연가심공이 사용 가능하면 활성화 후 필살.
- 0<잔여쿨<=N: 보존 정책은 키를 누르지 않고 일반 집중스킬 진행. 준비 후 중간삽입, 일반4개 완료해도 집중에서 기다림.
- 잔여쿨>N: 적룡포 직전 연가심공 사용. 필살은 다음 집중 진입까지 보류한다. 무연가심공 필살은 금지한다.
- 난무에서 필살 사용 금지. 패턴상 백불가 동안 일반스킬 진행 가능. N 기준으로 예약한 필살이 준비되어도 이미 시전 중인 스킬 취소 금지. 기존 ‘준비 시 사용/다음 사이클’ 옵션과 N 정책을 중복 적용하지 않는다.
- 연가심공 소모 사실과 필살 준비 상태로 판단한다. 임의 대미지 배율이나 필살 실패확률은 넣지 않는다.

통과: 7.5초 정확경계, 일반4개후대기, 필살취소시쿨/소모유지, 난무준비→집중사용, 일반쿨대기중필살준비, 원본커서복귀, 청룡진유무와 독립적인 필살사용.

### P4 이동과 실력 행동 (S4→S5)

R3/Q7에 따른 위치 모델을 먼저 완성하고 이후 Q3/Q4의 인지·예측 값을 적용한다. 전조정보가 없으면 사전 예측을 구현 완료로 표시하지 않는다. 같은 조건의 타격 피해는 수준별로 동일하고, 차이는 사용시각·버프획득·취소·실제 위치에서 발생한다.

통과: 이동시간 보존, 쿨과 중복합산 없음, 미래정보 누출 없음. 사용자 선택 정책을 수준과 무관하게 유지하고, 인지·반응·경로 효율만 승인된 값으로 적용한다.

### P5 실제 입력 검증·화면 연결·인수인계 (S6→S7)

- 실제 로드 세팅을 식별하고 전투시간/횟수/원본순서/정책/모델버전 기록. 가상 검증과 분리한다.
- 프리딜부터 전체전투까지 단계별 검증, 독립100회 묶음 반복 및 개발용 동일 조건 원인 비교.
- 스킬별 청룡진 적용 타격률, 연가심공 적용횟수, 필살예약대기, 전환횟수/시간, 쿨비/백률/원인별 대기를 진단에 추가한다.

### 아직 답변이 필요한 실제 충돌

- B1 확정: 첫 난무만1회 예외. 이후 난무는 서로 다른 스킬2개. 임의 스킬 삽입 금지.
- B2 확정: 사두 사례와 집중3회 이후 굉열파잔여50%이상 생략. 다른 스킬로 확대하지 않는다. 분모는 현재 세팅 최종 쿨로 확정, 난무는 서로 다른 스킬2개로 확정.
- B3 확정: 맹룡열파 없는 구성은 실행 차단하고 스킬명을 안내한다. 맹룡이 준비 상태면 잔여쿨0으로 청룡진 조건을 만족한다. 맹룡이 다음 구간에 있다는 이유만으로 임의 시전하지 않는다.
- B4 확정: 원본 필살 카드는 사용 가능 스킬 선언/추적용이다. 실제 사용 위치는 집중 진입 N초 예약 정책으로 결정한다. 일반 스킬 순서는 유지하고, 필살 사용 후 미사용 일반 카드로 복귀한다. 원래 카드 위치에서 중복 시전하지 않는다. 예약은 연가심공 미활성 상태의 보존이며, 실제 필살 시전 직전에 키를 사용한다. 반복 카드로 예약/사용 기회를 중복 생성하지 않는다.
- B5 확정: 횟수 충족은 전환 가능한 최소 조건이지 강제 전환 지시가 아니다. 굉열파 생략 조건이 되어도 남은 지정 스킬인 사두가 준비됐다면 사용한 뒤 전환한다. 준비된 나머지 지정 카드를 횟수 충족만으로 버리지 않는다. 이미 사용한 스킬을 반복 추가하는 의미는 아니다.
- B6 확정: 360 종료 후 맹룡·반월·청룡진을 포함한 일반 난무 구간부터 재개한다. 첫 청룡진 단독 구간으로 커서를0 초기화하지 않는다. 첫 난무 예외 재발급 및 임의 스킬 삽입은 금지한다. 쿨/미사용 장부를 보존한다.
- Q3/Q4/Q6: 행동 초기값(60% 포함), 전조정보, 관측 쿨비 시간 기준. 기본 엔진과 분리하여 실력 보정 전에 결정.

### 실행 순서와 중단 조건

P0→P1→P2→P3→P4→P5가 유일한 진행 순서다. S0~S7은 연결된 상세 검사 목록이다.
P0와 고정 사건 테스트·보스 계약 검토는 즉시 가능하다. B1~B6은 확정이며 다시 질문하지 않는다. Q3/Q4/Q6의 미확정 행동 모델 값을 임의 구현하지 않는다. 테스트 조건을 낮추지 않는다.

### 다음 구현자용 행동 판단 순서

1. 현재 보스 사건·피격·완료 이벤트를 정해진 동시각 순서로 반영한다. 진행 중인 모션은 정책 판단으로 끊지 않는다.
2. 스탠스 진입이 완료되면 해당 방문의 사용 이력을 리셋한다. 집중이면 N초 기준 필살 예약을 한 번 결정한다.
3. 예약 필살이 준비됐다면 백 확보·입력 후 연가심공과 사용한다. 준비 전에는 원본 일반카드를 진행한다. 일반 구간이 끝났으면 예약 완료까지 기다린다.
4. 다음 일반카드가 청룡진이면 자체쿨과 맹룡열파잔여<=1초 조건을 검사한다. 대기 중 버프·사용 이력을 생성하지 않는다.
5. 다음 카드가 쿨이면 진입 후 사용 이력과 명시적 생략 규칙을 확인한다. 집중3회 미만이면 기다린다. 3회 이상에서 사두쿨이면 생략, 굉열파잔여비율>=.5면 생략·전환 판단. 다른 카드에는 예외를 확대하지 않는다.
6. 전환은 첫난무1/이후난무서로다른2개/집중3 기준과 예약 상태를 검사한다. 준비된 나머지 카드를 단지 기준 횟수가 찼다는 이유로 생략하지 않는다.
7. 모든 생략은 원본 보존·미사용 로그로 남긴다. 다음 판단 시각은 실제 쿨/사건/행동 완료로 예약하고 같은 시각 반복 루프로 시간을 소모하지 않는다.

이 순서는 구조 지침이다. B1~B6의 확정 계약과 Q3/Q4/Q6의 미확정 행동 보정값을 구분하며, 계획 확정을 엔진 구현 완료라고 보고하지 않는다.

각 단계 결과는 구현 파일, 고정 입력, 기대/실제 값, 테스트 명령, 미해결 ID, 다음 작업으로 기록한다. 테스트 수와 실전 정밀도를 동일시하지 않는다.
사용자 입력을 질문하더라도 독립적인 검증은 계속한다. 배포는 이 작업의 완료 조건이 아니다.

## 일반 계산 경로 영향 분석 (2026-09-22)

현재 일반 계산은 시뮬레이션 엔진과 별도 경로다.

- `calculateGuidelineCycleSeconds()`는 비222 절정에서 적룡포 최종 쿨타임×3을 사용하므로, 조우·반복 분리와 필살 예약을 반영하지 않는다.

- 막대그래프·스킬 비교 데이터도 같은 `cycleDamageRows`에서 파생되므로 동일한 영향이 전파된다.

따라서 현재 값은 새 시뮬레이션 결과가 아니라 기존 정적 사이클 예상값이다. 조우 피해를 반복 DPS에 매번 더하지 않도록 수정하려면 조우 1회 피해와 반복 방문 피해의 시간·필살 빈도 기준을 먼저 확정해야 한다. 해당 기준이 확정되기 전에는 산식을 변경하지 않는다.

- 360줄 기믹은 시작 후 30초를 공격 가능·전부 백어택 판정으로 분리하고, 남은 30초 또는 50초를 딜 불가로 처리했다. 320줄은 첫 30초 동안 스킬 시전·쿨·백어택 판정은 진행하지만 피해 배율을 0으로 처리하고, 이후 20~30초 50% 피해 + 10초 정상 피해 + 5초 딜 불가로 총 65~75초다.

### 상태 분리 1차 적용 (2026-09-22)

- 새 실행 경로에서 하나의 `busyUntil`에 섞여 있던 상태를 `controlUntil`, `castUntil`, `stanceSwitchUntil`로 분리했다.
- 상태이상은 `controlUntil`, 실제 시전 종료는 `castUntil`, 스탠스 전환은 `stanceSwitchUntil`을 사용한다.
- 예약 필살이 백어택 불가 구간에 도달했을 때 필살만 보류하고 일반 집중 카드를 계속 처리하도록 수정했다.
- 모든 스킬의 초기 준비 시각을 전투 시작 0초로 명시해 첫 사용 전 대기가 일반 쿨비와 필살 원인별 장부에서 동일하게 집계되도록 수정했다.
- 레거시 실행 경로는 기존 동작을 보존했고, 새 순서 방식 실행 경로에만 상태 분리를 적용했다.
- 검증 결과: TypeScript 통과, 시뮬레이션 단위 테스트 39개 통과.
- 브라우저 실제 세팅의 필살 준비 후 미사용 시간에 보스 타임라인 source별 세분 집계를 추가했다. 660초·500회 실행에서 강제 딜 불가 91.38초 중 360줄 58.66초, 320줄 17.60초, 앵버 3.29초로 확인되었고, 나머지는 개별 기본 패턴별로 표시된다.

남은 검증:

- 상태 분리 후 경직·넘어짐·시전 취소가 동시에 발생하는 결정적 테스트를 추가해야 한다.
- 실제 현재 세팅 브라우저 실행이 새로고침 후 결과를 생성하지 않는 원인을 확인해야 한다.

### API 운영 방식 전환 보류 (2026-09-27)

- 사용자 개인 키를 서버 운영용 키로 대체하는 API 프록시·캐시 구조는 별도 구현 계획으로 기록했다.
- 해당 전환은 현재 시뮬레이션 작업 범위에서 제외하고, 실력 행동 모델·필살 예약 판단·쿨비 검증을 우선한다.

### 적룡필살 판단 실수 모델 연결 (2026-09-27)

- 행동 프로필에 예약 판단 누락 확률과 준비 확인 지연 확률을 추가했다. 공식은 각각 `MIN(40, MAX(0, 1.8 × (90 - 수준)))%`, `MIN(40, MAX(0, 0.9 × (90 - 수준)))%`이며 100·90%는 0%다.
- 반복 집중 진입에서 `C <= N`인 경우에만 방문별로 예약 판단을 한 번 추첨한다. 누락되면 해당 집중 방문에는 재예약하지 않고 기존 일반 스킬 흐름으로 진행한다.
- 예약에 성공한 방문은 필살을 실제로 선택할 수 있는 시점에 준비 확인 지연을 한 번 추첨한다. 발생 시 다음 미사용 일반 카드 정확히 하나를 시전한 후 필살로 복귀하며, 조건부 생략은 사용으로 세지 않는다.
- 방문별 진단 결과에 예약 가능 방문, 예약 누락, N초 초과 보류, 준비 확인 판정·발생, 선행 일반 카드 ID, 일반 카드가 없을 때 즉시 진행한 횟수를 추가했다.
- 검증 결과: TypeScript 통과, 전체 단위 테스트 105개 통과. 확률 표 검증을 추가했다.
- 미검증: 실제 현재 세팅 660초·500회에서의 판단 실수 빈도 및 쿨비 영향은 브라우저 세팅 연결 검증 단계에서 확인해야 한다.
