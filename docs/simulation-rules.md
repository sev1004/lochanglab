# 시뮬레이션 규칙

이 문서는 창술사 DPS 시뮬레이터의 계산 기준을 정의한다. 구현 전 반드시 규칙을 확정하고, 규칙이 바뀌면 기준 시나리오와 회귀 테스트를 함께 갱신한다.

## 1. 기본 정의

- DPS: 총 피해량을 실제 전투 시간으로 나눈 값
- 전투 시간: 사용자가 입력한 초 단위 시간
- 총 피해량: 시뮬레이션 중 발생한 모든 유효 피해의 합
- 기준 시나리오: 동일한 입력으로 결과를 재현하기 위한 고정 테스트 시나리오

기본 계산식:

```text
DPS = 총 유효 피해량 / 실제 전투 시간
```

## 2. 시뮬레이션 입력

최소 입력 모델은 다음을 포함한다.

- 캐릭터 스탯: 공격력, 치명, 특화, 신속 등
- 장비 및 세트 효과
- 각인
- 스킬, 트라이포드, 룬, 보석
- 전투 시간
- 스킬 사용 순서 또는 자동 행동 정책
- 대상 방어력과 적용할 방어력 감소
- 버프·디버프 조건

입력에는 `dataVersion`과 `simulationVersion`을 기록한다.

## 3. 이벤트 기반 처리

시뮬레이터는 시간순 이벤트를 처리한다.

```text
전투 시작
→ 상태 초기화
→ 사용 가능한 행동 선택
→ 스킬 실행
→ 피해 이벤트 계산
→ 버프·디버프·자원 갱신
→ 쿨다운 갱신
→ 다음 이벤트 처리
→ 전투 종료
```

스킬의 실제 재사용 대기시간, 시전 시간, 후딜, 자원 소모를 모델에 반영한다. 구현되지 않은 요소는 임의로 적용하지 말고 명시적인 가정으로 표시한다.

## 4. 피해 계산 순서

정확한 게임 공식이 확인되기 전까지 계산 순서는 다음 단계로 고정한다.

1. 스킬 기본 피해량 산출
2. 스탯 및 스킬 계수 적용
3. 트라이포드·보석·각인 효과 적용
4. 공격력·피해 증가 버프 적용
5. 치명타 여부 및 치명타 배율 적용
6. 대상 방어력과 방어력 감소 적용
7. 최종 피해 반올림 및 기록

게임 공식이 확인되면 이 순서와 예외 규칙을 버전 관리한다.

## 5. 치명타와 확률

초기 버전은 결과 재현성을 위해 기대값 기반 계산을 우선한다.

```text
기대 피해량 = 일반 피해량 × (1 - 치명타 확률)
             + 치명타 피해량 × 치명타 확률
```

랜덤 샘플링을 지원할 경우 seed를 입력에 포함하고, 평균·최솟값·최댓값·표준편차를 함께 표시한다.

## 6. 버프·디버프

모든 버프와 디버프는 다음 정보를 가진다.

- 적용 시작 시각
- 지속 시간
- 중첩 수
- 갱신 규칙
- 적용 대상
- 피해 계산에서의 적용 위치

버프가 적용된 피해 이벤트에는 어떤 효과가 적용됐는지 기록하여 결과를 설명할 수 있어야 한다.

## 7. 결과 출력

최소 출력값:

- 총 피해량
- DPS
- 스킬별 피해량과 기여율
- 스킬 사용 횟수
- 치명타 횟수 또는 기대 치명타 기여
- 적용된 전투 시간
- 데이터 버전 및 계산 버전

결과 화면에는 계산에 사용한 가정과 미지원 요소를 숨기지 않고 표시한다.

## 8. 미정·제외 항목

아래 항목은 게임 공식과 구현 범위를 확인한 뒤 추가한다.

- 모든 직업 및 모든 스킬
- 실제 서버 틱·프레임 단위 지연
- 플레이어의 입력 오차
- 파티 시너지 조합 전체
- 패치별 과거 데이터 자동 전환

미지원 요소는 결과에 영향을 줄 수 있으므로 `assumptions` 목록으로 관리한다.
